# One Piece Logo - CSS Art Project

A pure CSS recreation of the iconic Straw Hat Pirates Jolly Roger from the anime/manga One Piece. This project demonstrates CSS positioning, shapes, and styling techniques to create complex graphics without any images or SVG files.

## 🎨 Preview

The logo features:
- Skull with eyes and nose
- Crossed bones behind the skull
- Luffy's signature straw hat
- Red hat band
- Wide hat brim
- Decorative circular elements
- Teeth details

## 🚀 Quick Start

1. Clone or download the project files
2. Open `index.html` in your web browser
3. The One Piece logo will render automatically

No build tools or dependencies required!

## 📁 Project Structure

```
one-piece/
│
├── index.html      # HTML structure with logo elements
├── styles.css      # All styling and positioning
└── README.md       # Project documentation
```

## 🛠️ Technologies Used

- **HTML5** - Semantic structure
- **CSS3** - Advanced positioning and styling
  - Absolute positioning
  - Border manipulation
  - Border radius for circular shapes
  - Transform and rotation
  - Z-index layering

## 🎯 Features

- **Pure CSS Art** - No images or external assets
- **Responsive Layout** - Centered using flexbox
- **Dark Theme** - Black background to enhance the logo contrast
- **Layered Design** - Proper z-index management for depth

## 💡 CSS Techniques Demonstrated

1. **Shape Creation** - Using borders and border-radius to create circles and curved shapes
2. **Absolute Positioning** - Precise placement of all logo elements
3. **CSS Transforms** - Rotation for crossbones at 45-degree angles
4. **Layering** - Z-index to control element stacking order
5. **Border Manipulation** - Selective border removal for unique shapes

## 📝 Customization

You can easily customize the logo by modifying `styles.css`:

- **Colors**: Change `background` properties (e.g., straw hat yellow `#ffda3c`, red band)
- **Size**: Adjust the `.logo` width and height, then scale child elements proportionally
- **Position**: Modify `top`, `left`, `bottom`, `right` values
- **Rotation**: Change `transform: rotate()` values for the crossbones
