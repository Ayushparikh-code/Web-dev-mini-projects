# ❤️ Love Calculator App

**Welcome to the Love Calculator!** This is a fun and good-looking web app where friends and couples can calculate their love percentage. It is a very simple and interesting project to play with or learn from!

## ✨ Features

* **Fun & Interactive:** Just type in two names and find out the love score!
* **Beautiful Design:** A clean, nice-looking interface that is easy to use.
* **Great for Beginners:** A perfect mini-project to see how basic web coding works together.

## 🛠️ Technologies Used

This project is built using the three main building blocks of the web:

* **HTML:** To build the structure of the webpage.
* **CSS:** To add pretty styles, colors, and layout.
* **JavaScript:** To do the math and create the random love percentage!

## 🚀 How to Run It on Your Computer

It is super easy to get this running! You don't need to install any special software.

1. **Download the code:** Save the project folder to your computer.
2. **Find the file:** Open the folder and look for the `index.html` file.
3. **Open in Browser:** Double-click `index.html`. It will open right up in Chrome, Edge, Safari, or whatever web browser you use.
4. **Test it out:** Enter some names, click the button, and see the results!
