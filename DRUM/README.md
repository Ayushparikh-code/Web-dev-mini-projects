# 🥁 Drum Kit

**Welcome to the Drum Kit!** This is an interactive and fun web application that lets you make your own music right in your browser. Whether you want to click on the screen or jam out using your keyboard, this virtual drum kit has all the beats you need to get started!

## ✨ Features

* **Interactive Interface:** Click directly on the drum images or the alphabet letters on the screen to play a beat.
* **Keyboard Support:** Use the corresponding keys on your physical keyboard to play the drums, making it feel like a real instrument!
* **Make Your Own Music:** Combine different sounds and beats to create your own unique tracks.
* **Instant Audio Feedback:** Smooth and quick sound playback using JavaScript.

## 💻 Tech Stack

This musical web app is built using the core technologies of the web:

* **HTML5:** To structure the layout and add the audio elements.
* **CSS3:** To style the drums, add animations when keys are pressed, and make the app look great.
* **JavaScript:** To listen for mouse clicks and keyboard presses, and to trigger the correct audio files.

## 🚀 How to Play on Your Computer

It is incredibly easy to set up your own virtual drum kit. You do not need to install any special software!

**1. Download the code:** Open your terminal and clone the repository:
```bash
git clone [https://github.com/Ayushparikh-code/Web-dev-mini-projects.git](https://github.com/Ayushparikh-code/Web-dev-mini-projects.git)
2. Open the project folder: Navigate into the main repository folder and find the Drum Kit directory.

3. Start the Drum Kit: Find the index.html file inside the folder and double-click it. It will open up in your default web browser (like Chrome, Firefox, or Safari).

4. Start Playing: Click the drums on the screen or press the matching keys on your keyboard to start making music!
