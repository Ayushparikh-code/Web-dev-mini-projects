# 🏓 Ping Pong Game

**Welcome to the Ping Pong Game!** This is a fun, classic arcade game built for the web. It is a great mini-project to see how game logic, movement, and collision work in a web browser!

## ✨ Features

* **Classic Gameplay:** Hit the ball back and forth and try to score points!
* **Score Tracking:** Automatically keeps count of the points during the game.
* **Simple Controls:** Easy to play using just your keyboard.
* **Great for Beginners:** The code is simple and easy to learn from.

## 🛠️ Technologies Used

This game is built with the three basic building blocks of the web:

* **HTML:** To set up the game board canvas.
* **CSS:** To style the game area and make it look nice.
* **JavaScript:** To make the ball move, control the paddles, and calculate the score!
