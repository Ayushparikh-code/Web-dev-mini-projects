# 🗣️ Text to Speech Converter

**Welcome 🖐 to the Text to Speech Converter!** This is a simple, intuitive web application that brings your words to life. Just type in whatever you want to hear, and the app will read it out loud to you! It is a great mini-project to learn about web accessibility and browser APIs.

## ✨ Features

* **Instant Audio:** Converts your written text into spoken audio instantly.
* **Easy to Use:** A simple and clean interface—just type and listen!
* **Beginner Friendly:** A great showcase of how to use JavaScript to interact with built-in browser speech functionalities.

## 💻 Tech Stack

This project is built using the core technologies of the web:

* **HTML5:** To build the structure and the text input area.
* **CSS3:** To style the application and make the interface look great.
* **JavaScript:** To capture the text and trigger the browser's Text-to-Speech API.

## 🚀 How to Run It on Your Computer

It is very easy to get this app running locally. No special software or server is needed!

**1. Download the code:** Open your terminal and clone the repository:
```bash
git clone [https://github.com/Ayushparikh-code/Web-dev-mini-projects.git](https://github.com/Ayushparikh-code/Web-dev-mini-projects.git)
2. Open the project folder: Navigate into the main repository folder and find the Text to Speech directory.

3. Run the app: Find the index.html file inside the folder and double-click it. It will open right up in your default web browser (like Chrome, Firefox, or Edge).

🎧 How to Use
Write your text: Click on the text box and type or paste the text you want to listen to.

Submit: Click the "Submit" button.

Listen: Make sure your volume is up and listen to the audio playback!
