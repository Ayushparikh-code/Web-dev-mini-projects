# ⏱️ Focus Timer

A simple and clean **Focus Timer** built using **HTML, CSS, and JavaScript**. This mini‑project lets users set a custom time, start/pause/reset the countdown, and view progress visually through an animated circular indicator.

---

## 🚀 Features

* Set custom minutes
* Start, Pause, and Reset controls
* Animated circular progress bar
* Clean minimal UI
* Uses pure HTML, CSS, and JavaScript (no libraries)

---

## 🗂️ Project Structure

```
/project-folder
│── index.html
│── style.css
└── home.js
```

---

## 📦 Installation

1. Download or clone the project folder.
2. Make sure all three files (`index.html`, `style.css`, `home.js`) are in the same directory.
3. Open **index.html** in any web browser.

---

## 🖥️ How It Works

* Enter the number of minutes in the input box.
* Click **Start** to begin the timer.
* The circular ring shrinks based on remaining time.
* **Pause** stops the timer without resetting.
* **Reset** stops the timer and clears progress.
