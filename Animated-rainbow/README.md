# 🌈 Animated Rainbow

**Welcome to the Animated Rainbow project!** This is a beautiful and simple web project that displays a glowing, animated rainbow. The best part? It achieves this stunning visual effect using absolutely zero JavaScript! It is a fantastic example of the power of CSS animations.

## ✨ Features

* **Pure CSS Animation:** Smooth and colorful animations powered entirely by modern CSS.
* **No JavaScript Required:** Highly lightweight and fast, demonstrating what can be done with just markup and styling.
* **Beginner Friendly:** A great resource for learning about CSS keyframes, positioning, border-radius, and transitions.

## 💻 Tech Stack

This project is built using only the core styling and markup languages of the web:

* **HTML5:** To create the structure and elements of the rainbow.
* **CSS3:** To style the vibrant colors and bring the rainbow to life with smooth animations.

## 🚀 How to Run It on Your Computer

It is incredibly easy to run this project locally. You do not need to install any special software!

**1. Download the code:** Open your terminal and clone the repository:
```bash
git clone [https://github.com/VaibhavSuryavanshi93/Web-dev-mini-projects.git](https://github.com/VaibhavSuryavanshi93/Web-dev-mini-projects.git)
2. Open the project folder: Navigate into the downloaded repository folder.

3. Run the animation: Find the Rainbow.html file inside the directory and double-click it. It will open right up in your default web browser (like Chrome, Firefox, or Safari), and the animation will start playing immediately!
